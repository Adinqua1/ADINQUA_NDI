"# ADINQUA\_NDI"

Pi-Pi Stacking of NDIs and PDIs.

This project talks about the Pi-Pi stacking of organic molecules from NTCDA when they undergo condensation reaction with primary amines such as Aminoethanol, octylamine, propylamine, and so on. This Pi-stacking molecules can be used in polymer chain reactions, electronics, drug delivery with varying color identifications.
# Exploratory Data Analysis of NTCDA-Amine Condensation and $\pi$-Stacking Yields

## Project Description
This project performs an exploratory data analysis (EDA) on primary experimental laboratory data investigating the synthesis of Naphthalene Diimide (NDI) derivatives from 1,4,5,8-naphthalenetetracarboxylic dianhydride (NTCDA) and various primary amines. The analysis evaluates how experimental parameters—specifically amine structure/bulk and reaction temperature—impact percentage yield and $\pi$-stacking characteristics, assessing parameter space coverage, sampling resolution, and reaction condition overlaps.
